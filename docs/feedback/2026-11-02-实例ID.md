# 2026-11-02 · 实例 ID 不跟随名称

- 来源：用户反馈
- 版本：1.0.0 开发中

## 现象

新建实例时改中文名，ID 仍是 `instance`（或固定值），改回英文名也不更新。

## 期望

ID 跟随名称自动生成，且改名后不用手动再填一次。

## 根因

1. 原实现用拼音首字母转写，中文全落空 → 兜底成 `instance`；
2. `autoId` 只在 ID 为空时赋值，用户填过（或兜底过）就不再跟随。

## 处理

- 弃用拼音转写，改为**统一哈希 ID**：`inst-` + FNV-1a 64 位取 base36 前 8 位；
- 名称变化时，只要用户没手工改过 ID 就跟随重算；
- 中文名 → `inst-xxxxxxxx`，路径短且稳定（早期 pinyin 方案路径过长）。

## 遗留

哈希不可逆，用户无法从 ID 看出名称来源——这是刻意的（可读性交给 `name` 字段）。
