# 2026-11-01 · 双击无反应

- 来源：用户反馈
- 版本：0.1.x（首次交付）
- 环境：受限权限环境

## 现象

双击 `DSH-NEXT-Multi.exe` 没有窗口，进程一闪而过，数据目录里什么都没有。

## 期望

至少能看到窗口，或看到失败原因。

## 根因

1. WebView2 数据目录默认在 `%LOCALAPPDATA%`，受限环境下不可写 → 窗口构建失败；
2. release 是 GUI 子系统没有控制台 → `setup` 的错误被吞掉。

## 处理

- 窗口显式 `data_directory`，四档兜底（env → 数据目录 → 应用旁 → `%TEMP%`）；
- 启动期日志先于窗口初始化，失败也留痕；
- 全失败时写 `%TEMP%\DSH-NEXT-Multi-startup-error.txt` 并**弹框**说明具体原因与候选目录。

## 遗留

无。该路径已有验收：`docs/acceptance.md` §8.1、§8.2。
