# 2026-11-01 · 重启串台

- 来源：用户反馈
- 版本：0.9.x
- 环境：Win11，两个非默认实例同时运行

## 现象

在 DSH-NEXT 内部点「重启」（或其更新提示触发的重启），实例落到**默认**环境，看不到原来的会话。

## 期望

重启后回到该实例自己的数据目录。

## 根因

启动器在启动成功后把全局指针还原为 `defaultHome`；DSH-NEXT 重启会新起进程并重新读指针。
串台不是 bug 而是机制限制：指针全局唯一，且由应用内选择（指针文件）优先于环境变量。

## 处理

1. 把「重启」收敛到启动器：停止 → 等进程消失 → 写指针 → 重新启动 → 成功后还原；
2. 详情页与实例行各提供「重启 ▾」，含「重启 / 重启并进入安全模式 / 重启并退出安全模式」；
3. 顶部用轮播提示条说明「非默认实例的重启只能在启动器中正常使用」。

## 遗留

同时运行多个非默认实例时，指针只能指向最后启动的那个，其余实例的内部重启仍会串台。
彻底解决需要每实例重定向 `%APPDATA%`（风险较高，未实施）。
