# 06 · 窗口创建失败

## 症状

双击 exe 后窗口不出现（或闪一下），数据目录里没有 `app.json`、也没有日志，完全静默。

## 根因

两条叠加：

1. WebView2 的用户数据目录默认落在系统位置（`%LOCALAPPDATA%\com.dshnext.multi-launcher`），
   该目录不可写时 `WebviewWindowBuilder::build()` 直接失败；
2. release 是 Windows GUI 子系统（`windows_subsystem = "windows"`），**没有控制台**，
   `setup` 返回的错误被吞掉，用户只看到"打不开"。

## 证据

```text
$ .\DSH-NEXT-Multi.exe
thread 'main' panicked at tauri-2.12.5/src/app.rs:1444:
Failed to setup app: error encountered during setup hook: 拒绝访问。 (os error 5)
exit code 101
```

数据目录为空、无日志，说明失败发生在 `build_state` 之前。

## 结论

- 窗口显式指定 `data_directory`，按 `DSH_MULTI_WEBVIEW_DATA` → `<数据目录>\webview2` →
  `<应用根>\DSH-NEXT-Multi-data\webview2` → `%TEMP%\...` 依次尝试；
- 日志在窗口创建**之前**初始化（目录不可写则退到临时目录）；
- 三档都失败时：写日志 + 写 `%TEMP%\DSH-NEXT-Multi-startup-error.txt` + **弹框**说明原因，不再静默退出。

对应实现：`lib.rs` 的 `startup_logger` / `fatal` / `build_main_window`。
