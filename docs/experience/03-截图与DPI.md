# 03 · 窗口截图与 DPI

## 症状

Tauri 窗口截图里只能看到左侧列表，详情面板"不见了"，一度怀疑是布局溢出。

## 根因

显示器 150% 缩放，`PrintWindow` / `GetWindowRect` 在非 DPI-aware 进程里拿到的是**虚拟化后**的尺寸：

- 真实窗口：`1680 × 1140` 物理像素（CSS 视口 1120 × 760）；
- 截图工具报告：`1135 × 797`，只覆盖窗口左上约 2/3。

详情面板落在被裁掉的右侧，于是"看起来消失了"。

## 证据

启动日志里主动记录了窗口尺寸（`lib.rs` 的 setup）：

```text
[INFO] 窗口内尺寸 1680x1140 物理像素，scale=1.5 → CSS 视口约 1120x760
```

用 760×520 的窗口复截（`DSH_MULTI_WINDOW_SIZE=760x520`）后，详情面板完整出现，布局问题排除。

## 结论

- 判断"布局是否溢出"要用**日志里的 CSS 视口**，不要相信截图工具的像素数；
- 截图脚本要 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，或直接改用浏览器同尺寸截图；
- 这条能力（窗口尺寸写日志）保留在 `src-tauri/src/lib.rs` 的 setup 里，排障时一眼分清"窗口太窄"还是"布局溢出"。
