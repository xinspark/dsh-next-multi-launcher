# 02 · 进程扫描

## 症状

启动器列表里所有实例都显示「已停止」，但任务管理器里 `DSH NEXT.exe` 明明在跑。

## 根因

`sysinfo` 0.33 的 `refresh_processes_specifics` 默认 `ProcessRefreshKind` 只采集基础字段，
**不采集命令行**。`cmd()` 恒为空字符串，于是：

- `--user-data-dir=<home>` 解析不出来 → 无法把进程归到某个 home；
- `is_dsh()` / `is_host()` 判据全部失效。

## 证据

```text
# 修复前 --scan-debug
running []

# 修复后（同一时刻、同一机器）
running [{"home":"C:\\Users\\<user>\\.dsh","shellPid":9560,"startedAt":1793519683}]
```

## 结论

`scan_processes()` 必须显式指定：

```rust
sysinfo::System::refresh_processes_specifics(
    ProcessesToUpdate::All,
    true,
    ProcessRefreshKind::everything(),
)
```

这条代价是扫描变慢，所以版本扫描做了 5 秒缓存；但漏掉命令行会让整个"按 home 归属"机制失效。
