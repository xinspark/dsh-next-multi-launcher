# 项目经验

每条经验固定四段：**症状 → 根因 → 证据 → 结论**。只写"踩过且可复现"的，
不写猜测；能变成测试或门禁的，已经在代码里落地。

| # | 主题 | 一句话结论 |
|---|---|---|
| 01 | [asar 读取](01-asar-读取.md) | `offset`/`size` 可能是 JSON 字符串；`unpacked` 条目的数据在 `<asar>.unpacked/` |
| 02 | [进程扫描](02-进程扫描.md) | `sysinfo` 默认刷新级别拿不到命令行，必须 `ProcessRefreshKind::everything()` |
| 03 | [窗口截图与 DPI](03-截图与DPI.md) | 150% 缩放下 `PrintWindow` 只截到窗口左上 2/3，用日志里的 `inner_size` 取证 |
| 04 | [图标与缓存](04-图标与缓存.md) | 改 `icons/` 后 `pnpm tauri build` 不更新内嵌图标，要 `cargo clean -p` |
| 05 | [指针与重启](05-指针与重启.md) | 启动成功即还原指针 → DSH-NEXT 内部重启会落到默认实例 |
| 06 | [窗口创建失败](06-窗口创建失败.md) | WebView2 数据目录不可写会让 `setup` 直接 panic，且 GUI 子系统没有控制台 |
| 07 | [自动扫描扫不出中文路径](07-扫描乱码.md) | 路径不要跨进程 stdout 传递：PowerShell 5.1 的代码页会把中文变成 `?`，改用原生 COM/winreg |
| 08 | [原地升级后版本号还停在旧版](08-原地升级与版本号.md) | `versions\<tag>` 的目录名是登记时写死的，链接目标被原地升级后要启动时对账改名 |
| 09 | [每次切换实例都弹「数据目录与上次不同」](09-数据目录确认框.md) | 除指针外还要同写 `desktop-next-last-home.json`，否则默认按钮会把启动改回上一个实例 |

## 写作约定

- 一条经验只讲一件事；跨主题的拆成两条。
- 证据必须是**命令 + 输出**，不是"我记得"。
- 结论要能指导下一次：要么写成检查项，要么写成代码里的门。
