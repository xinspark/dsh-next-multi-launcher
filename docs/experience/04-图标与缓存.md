# 04 · 图标与缓存

## 症状

换掉 `src-tauri/icons/source.png` 并重新 `pnpm tauri icon` 后，双击 exe 看到的还是旧图标。

## 根因

两层缓存，缺一不可：

1. **构建缓存**：`tauri-build` 的 build script 负责把 `icons/icon.ico` 嵌进 Windows 资源；
   只改图标文件不会让它重跑，`cargo` 认为二进制没变化；
2. **Explorer 图标缓存**：即使 exe 已更新，资源管理器仍显示 `IconCache.db` 里的旧图。

## 证据

```powershell
# 从 exe 直接提取内嵌图标（绕过 Explorer 缓存）
Add-Type -AssemblyName System.Drawing
$i = [System.Drawing.Icon]::ExtractAssociatedIcon((Resolve-Path "DSH-NEXT-Multi.exe").Path)
$i.ToBitmap().Save("target/exe-icon.png")

# 重建前：旧图标（蓝底白方块）
# cargo clean -p dsh-next-multi-launcher --release 后重建：新图标（四宫格 + 鲸鱼）
```

## 结论

换图标的完整流程：

```powershell
pnpm tauri icon src-tauri/icons/source.png
cargo clean --manifest-path src-tauri/Cargo.toml -p dsh-next-multi-launcher --release
pnpm tauri build --no-bundle
# 然后刷新 Explorer
Stop-Process -Name explorer -Force; Start-Process explorer
```

同理：**只改前端（dist）也要 touch 一下 `lib.rs`**，否则 Rust 侧不会重新嵌入新的前端产物。
