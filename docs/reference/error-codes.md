# 错误码

所有错误都是 `{ code, message, detail? }` 结构，`code` 稳定可用于分支。
中文文案在 `src-tauri/src/errors.rs` 统一维护，业务代码不要自己拼字符串。

| 码 | 含义 | 常见触发 | 处理建议 |
|---|---|---|---|
| `E1000` | 内部错误 / IO 失败 | 读 `app.json` 失败、序列化失败 | 看关联操作与日志上下文 |
| `E1001` | 无法写入指针文件 | `%APPDATA%\DSH NEXT\home` 无写权限、文件被占用 | 用管理员运行，或修复该目录 ACL |
| `E1002` | 指针回滚失败 | 启动失败后恢复原指针时写入又失败 | 手工检查指针文件内容 |
| `E1003` | 数据目录已被占用 | 同一 home 已有实例在运行 | 先停止那个实例，或换 home |
| `E1004` | 版本目录无效 | 缺 `DSH NEXT.exe` 或 `resources\app.asar` | 重新解包安装，或换版本 |
| `E1005` | 启动超时 | 超时内没看到该 home 的进程 | 查版本完整性、杀软拦截、指针权限 |
| `E1006` | 启动后进程立即退出 | 版本树损坏、参数不兼容 | 看日志里的退出码与版本号 |
| `E1007` | 不安全的删除目标 | 目标是盘根 / 系统目录 / 默认环境 | 该路径禁止删除，换目录 |
| `E1008` | 实例 ID 已存在 | 新建时 ID 与已有实例冲突 | 换 ID |
| `E1009` | 实例不存在 | 文件被手工删除或 ID 写错 | 刷新列表；必要时重建实例 |
| `E1010` | 版本正被实例引用 | 删除仍被实例使用的版本 | 先把相关实例切到别的版本 |
| `E1011` | 数据目录仍有进程占用 | 删除数据目录时该 home 还有进程 | 先停止实例 |
| `E1012` | 参数无效 | 路径为空/相对/盘根、ID 非法、超时越界 | 按错误详情修正输入 |

## 设计约定

- `code` 只增不改；新语义用新码。
- `message` 面向用户（中文），`detail` 放技术细节（路径、pid、原始错误）。
- 前端按 `code` 分支（例如 `E1003` 提示"换个数据目录"），不要匹配文案。
